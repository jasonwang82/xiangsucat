# 🐱 xiangsucat - 像素猫绘画工具

一个简单有趣的网页像素画编辑器，专为绘制可爱的猫咪图案而设计！

![像素猫预览](https://github.com/user-attachments/assets/104bad33-51d0-4f19-8d2f-539b999e273a)

## ✨ 项目简介

xiangsucat 是一个纯前端实现的像素画绘制工具，无需安装任何依赖，在浏览器中即可使用。项目预设了一个可爱的猫咪图案，用户可以自由修改或创作新的像素艺术作品。

## 🎨 核心功能

### 像素画布
- **4行可变网格布局**：共50个像素块
  - 第1行：12个像素块
  - 第2行：15个像素块
  - 第3行：13个像素块
  - 第4行：10个像素块

### 颜色系统
- 🎨 **自定义颜色选择器**：支持选择任意RGB颜色
- 🌈 **8种预设颜色**：黑色、白色、红色、青色、黄色、绿色、浅绿、粉色
- 💡 **智能颜色指示**：当前选中颜色会有明显的视觉反馈

### 交互操作
- 🖱️ **左键点击**：使用当前颜色绘制像素
- 🖱️ **右键点击**：清除单个像素（恢复为白色）
- 🖱️ **双击像素**：从已绘制的像素中拾取颜色

### 功能按钮
- 🗑️ **清空画布**：一键清除所有绘画内容
- 🔄 **重置猫咪**：恢复为预设的猫咪图案
- 📋 **复制到剪贴板**：导出像素数据（JSON格式 + ASCII艺术形式）

## 🚀 快速开始

### 在线使用

1. 克隆或下载本仓库
2. 用浏览器打开 `pixel-art/index.html` 文件
3. 开始创作你的像素艺术！

```bash
# 克隆仓库
git clone https://github.com/jasonwang82/xiangsucat.git

# 进入目录
cd xiangsucat/pixel-art

# 使用浏览器打开 index.html
```

### 本地开发服务器（可选）

如果你想使用本地服务器运行：

```bash
# Python 3
cd pixel-art
python3 -m http.server 8080

# Node.js
npx http-server pixel-art -p 8080
```

然后在浏览器中访问 `http://localhost:8080`

## 📖 使用说明

### 基本绘画流程

1. **选择颜色**：点击顶部的颜色选择器或预设颜色按钮
2. **开始绘画**：左键点击像素块进行绘制
3. **修改调整**：右键点击可清除单个像素
4. **拾取颜色**：双击已绘制的像素可选择该颜色
5. **保存作品**：点击"复制到剪贴板"按钮导出数据

## 🎯 设计灵感

猫咪图案的设计灵感来自于Unicode块字符：
- ▜ (上半块)
- ▛ (下半块)
- █ (全块)
- ▘ (象限块)

这些字符被巧妙地转化为像素画形式，创造出可爱的猫咪形象。
