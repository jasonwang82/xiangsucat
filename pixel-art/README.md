# 像素画板 - Pixel Art

A simple web-based pixel art drawing tool with a cute cat preset.

## Features

- **4×12 Pixel Grid**: Four rows with 12 pixels each for creating simple pixel art
- **Color Picker**: Full spectrum color picker for unlimited color choices
- **10 Preset Colors**: Quick access to commonly used colors
- **Cat Preset**: Pre-loaded cute cat face pattern
- **Copy to Clipboard**: Export your pixel art as text using block characters
- **Clear Canvas**: Reset the canvas with one click
- **Interactive Drawing**: Click individual pixels or drag to paint

## How to Use

1. Open `index.html` in a web browser
2. Select a color using the color picker or preset color buttons
3. Click on pixels to paint them with the selected color
4. Use the buttons to:
   - **清空画布** (Clear Canvas): Reset all pixels to white
   - **加载猫咪预设** (Load Cat Preset): Load the default cat pattern
   - **复制到剪贴板** (Copy to Clipboard): Copy pixel art as text

## Demo
