# 像素画 - 猫咪 🐱

一个简单的像素画绘制网页应用，用于绘制可爱的猫咪像素画。

## 功能特性

### 🎨 基本功能
- **像素网格**: 4行像素块，每行包含10-15个像素块
  - 第1行: 12个像素块
  - 第2行: 15个像素块
  - 第3行: 13个像素块
  - 第4行: 10个像素块

### 🖌️ 颜色选择
- 自定义颜色选择器（支持任意颜色）
- 8种预设颜色快速选择：
  - 黑色、白色、红色、青色、黄色、绿色、浅绿、粉色

### 🐱 猫咪预设
- 预设了一个可爱的猫咪图案
- 基于参考字符：▜ ▛ █ ▘
- 点击"重置猫咪"按钮可恢复猫咪图案

### 🎯 交互功能
- **左键点击**: 使用当前选择的颜色绘制像素块
- **右键点击**: 清除单个像素块（变回白色）
- **双击像素块**: 将该像素块的颜色设为当前绘画颜色
- **复制到剪贴板**: 将当前的像素画以JSON格式和文本图案复制到剪贴板

### 🔧 工具按钮
- **清空画布**: 清除所有像素块
- **重置猫咪**: 恢复为预设的猫咪图案
- **复制到剪贴板**: 复制像素画数据

## 使用方法

1. 在浏览器中打开 `index.html` 文件
2. 选择你喜欢的颜色（使用颜色选择器或预设颜色）
3. 点击像素块开始绘画
4. 右键点击可清除单个像素块
5. 双击像素块可选择该像素块的颜色
6. 使用工具按钮管理你的作品

## 技术实现

- 纯HTML + CSS + JavaScript实现
- 无需任何外部依赖
- 响应式设计，适配各种屏幕尺寸
- 支持现代浏览器的剪贴板API
